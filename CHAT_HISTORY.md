# Prompt 1

Build a React + Vite + TypeScript application named "Aura" using React-Bootstrap for layout and MUI components (TextField, Slider, Select, Button, Icons, Color Inputs where appropriate) for a modern UI.

Requirements:
- Three-panel layout: Palette (20%) | Canvas (60%) | Properties (20%).
- Palette: Text, TextArea, Image, Button.
- Implement drag from palette and free movement on canvas using ONLY native mouse events (mousedown, mousemove, mouseup). Do NOT use react-dnd, GrapesJS, Konva, interact.js, HTML5 canvas, or similar libraries.
- Select components on canvas.
- Dynamic properties panel updates based on selected component.
- Real-time property updates.
- Custom inline editor for Text/TextArea (contentEditable, no CKEditor).
- Preview (Desktop & Mobile) and Copy HTML.
- Undo/Redo (50+ history states).
- Persist editor state in localStorage.
- Clean, modular architecture with reusable components, hooks, and TypeScript types.
- Generate README.md, PROJECT_STRUCTURE.md, ARCHITECTURE.md (with architecture diagram in Mermaid), and CHAT_HISTORY.md.
- Follow best practices, responsive design, and attractive modern UI with Bootstrap + MUI.
